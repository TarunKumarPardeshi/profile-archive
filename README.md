## 🌟 Featured Engineering Projects

### 🌐 High Availability & Resilience
* **[Multi-Region Disaster Recovery Mesh](https://github.com/TarunKumarPardeshi/multi-region-disaster-recovery-mesh)**
  * *Tech:* AWS Route 53 ARC · DynamoDB Global Tables · Terraform · Chaos Engineering
  * Automated dual-region active-active failover across `ca-central-1` and `us-east-1` with 5-region consensus quorum. Achieved **RTO < 5s** and **RPO = 0 data loss** during blackout drills.

* **[Canary & Progressive Delivery Mesh](https://github.com/TarunKumarPardeshi/canary-progressive-delivery-mesh)**
  * *Tech:* Kubernetes · Argo Rollouts · Istio Service Mesh · Prometheus Analysis · Helm
  * Metric-driven progressive canary releases. Evaluates HTTP 5xx error budgets and p99 latency in real-time, executing instant automated zero-downtime rollbacks on regressions.

### 🛡️ Cloud Security & Governance
* **[AWS Enterprise Multi-Account Landing Zone](https://github.com/TarunKumarPardeshi/aws-enterprise-landing-zone)**
  * *Tech:* Modular Terraform · AWS Organizations · Service Control Policies (SCPs) · GitHub OIDC
  * Well-Architected multi-account landing zone with strict OU separation (`Core`, `Workloads`, `Sandbox`), sovereign region locks (`ca-central-1`/`us-east-1`), and zero static credentials via GitHub Actions OIDC.

* **[Zero-Trust Supply Chain Security Pipeline](https://github.com/TarunKumarPardeshi/zero-trust-supply-chain-security)**
  * *Tech:* Trivy · CycloneDX 1.5 SBOM · Sigstore Cosign · Kubernetes · Kyverno
  * End-to-end supply chain provenance. Enforces zero-tolerance vulnerability gates (0 Criticals), generates cryptographically attested SBOMs, and blocks unsigned containers via Kyverno admission webhooks.

* **[Cloud Infrastructure Drift Sentinel & Self-Healing](https://github.com/TarunKumarPardeshi/cloud-drift-sentinel-self-healing)**
  * *Tech:* AWS EventBridge · CloudTrail · AWS Lambda (Python) · Slack Block Kit · Terraform
  * Event-driven drift remediation that intercepts out-of-band console changes (e.g. open `0.0.0.0/0` security group rules), executes sub-2-second automated self-healing rollbacks, and alerts Slack.

### ⚡ Streaming, GenAI & Telemetry
* **[Real-Time Event Streaming Platform](https://github.com/TarunKumarPardeshi/realtime-event-streaming-platform)**
  * *Tech:* Apache Kafka (KRaft) · AWS MSK · Python AsyncIO · Pydantic V2 · DLQ · DynamoDB
  * High-throughput event pipeline with strict schema validation, exponential retry backoff, zero-data-loss Dead-Letter Queue (DLQ) diversion, and Prometheus telemetry.

* **[Enterprise GenAI Gateway on AWS Bedrock](https://github.com/TarunKumarPardeshi/genai-bedrock-enterprise-gateway)**
  * *Tech:* FastAPI · AWS Bedrock (Claude 3.5 Sonnet / Haiku / Titan) · Redis · FinOps Metering
  * Enterprise LLM proxy featuring prompt injection interception (OWASP LLM01), regex PII scrubbing, sub-5ms Redis semantic caching (cutting costs by 40%), and real-time FinOps token attribution per tenant.

* **[Agentic Incident Responder](https://github.com/TarunKumarPardeshi/agentic-incident-responder)**
  * *Tech:* Agentic AI · LLM Reasoning · Model Context Protocol (MCP) · Kubernetes · CloudWatch
  * Autonomous SRE incident triage pipeline querying telemetry, generating structured root cause analysis (RCA), and enforcing a strict Human-in-the-Loop (HITL) approval gate for remediations.

* **[AWS EKS Production GitOps Platform](https://github.com/TarunKumarPardeshi/aws-eks-gitops-platform)**
  * *Tech:* Amazon EKS · Terraform · ArgoCD · AWS KMS · IRSA · VPC Multi-AZ
  * Production Kubernetes platform deployed across 3 Availability Zones with strict IAM Roles for Service Accounts (IRSA), envelope KMS encryption, and automated App-of-Apps GitOps synchronization.
